# Ritik Vishwakarma — Cognisor-style Portfolio

A futuristic, responsive portfolio built with Next.js, Tailwind CSS, Framer Motion, Lucide and tsParticles.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Deploy

This project is ready for Vercel deployment. Import the repository, keep the default Next.js settings, and deploy.

## Personalize

Edit `app/page.tsx` to update:
- GitHub URL
- social URLs
- project links
- skills
- bio
- email address
